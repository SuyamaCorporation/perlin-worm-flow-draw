# Perlin Noise Worm Flow Field Draw

Hundreds of particle "worms" follow vector directions derived from a pure-JavaScript 2D Perlin noise field, leaving colorful trails that fade over time. As particles flow through the smooth noise field, organic swirling patterns emerge. All Perlin noise is computed in JavaScript with no external libraries.

## Features

- Custom Perlin noise implementation in pure JavaScript (no library)
- 50–500 configurable particles with independent color values and lifetimes
- Four color themes: Rainbow, Ocean, Fire, Monochrome
- Controls for particle speed, noise scale, trail fade rate, and particle count
- Time drift slider to animate the noise field, creating flowing animated patterns
